# Maryam Fahim Portfolio — React

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```

## WhatsApp

The visible page shows only a WhatsApp button. Clicking it opens the configured WhatsApp destination; the phone number is not displayed as page text.

## Important verified-data note

CGPA (3.75) and current semester (7th) are stored for Maryam AI's verified knowledge and are intentionally not displayed in the visible Education section.

The existing dark blue/purple theme and Technology Arsenal content are preserved. The React version also fixes the original custom-cursor behavior by allowing a real text caret inside inputs.
