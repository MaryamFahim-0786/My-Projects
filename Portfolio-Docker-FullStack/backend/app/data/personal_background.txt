## What Shapes My Work

### 1. Building things end to end
I like owning a feature from the data layer to the screen. My AI projects usually include a Python backend (FastAPI or Flask), an AI layer (LangChain / LangGraph / direct Gemini calls), a database (PostgreSQL with pgvector, ChromaDB or SQLite) and a user interface (Next.js or React).

### 2. Careful, safe engineering
In my Python systems (Bank Management System, Library Management System, Car Rental System) I focus on the details that make software trustworthy: salted password hashing (PBKDF2), input validation, exact Decimal arithmetic for money, database transactions with rollback, role-based access, CSV report export and unit tests where the project has them.

### 3. Grounded AI
In my RAG projects the goal is that the model answers from real documents and shows which chunks were used, instead of guessing. I care about retrieval quality, citations, conversation memory and choosing the right tool for each question.

### 4. Learning by shipping
I learn new tools by building something with them: LangGraph for the weather agent, pgvector for semantic search, Electron for a desktop wrapper, Leaflet and Recharts for data visualisation.
